# Biblioteca local autorizada

Nenhum vídeo de terceiros é incluído. Coloque aqui somente gravações próprias/autorizadas.
Crie `biblioteca.json` com uma lista como esta, substituindo todos os dados pelos termos reais:

```json
[
  {
    "id": "epi-turno-a",
    "titulo": "Verificação de EPIs",
    "descricao": "Gravação autorizada para análise local.",
    "arquivo": "epi-turno-a.mp4",
    "autorizado": true,
    "licenca": "Registro ou termos da autorização real"
  }
]
```

Somente arquivos existentes dentro desta pasta, com extensão aceita e autorização declarada, aparecem
na interface. O vídeo também precisa passar pela verificação de decodificação ao ser selecionado.
Não use quedas perigosas para coletar demonstrações. A biblioteca e seus metadados estão ignorados
pelo Git, com exceção deste README. Os resultados são sempre calculados pelos modelos, sem roteiros de alertas.
